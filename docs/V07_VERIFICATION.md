| Source counts | 386 configured scopes / 322 default scopes; these remain connection/routing counts, not asset/site counts. No new source count is claimed for reader support. |

Tests are focused evidence, not an exhaustive validation of all provider inventories, PSD features, USD extensions, Blender versions, codecs or professional assets. Some visually benign original textures triggered the conservative classifier and remained withheld. Those failures were not bypassed or declared safe.

The public-source checks uncovered and fixed query-window exhaustion in Khronos and premature page quotas in creator pack search. Kenney now uses its observed public `search` form and packs include bounded shared texture atlases. Original byte checks remain in place for every delivery.

Blender jobs use fixed software, disabled asset autoexec, no inherited MCP stdin, no GitHub/provider credentials, bounded CPU/pose/file sizes and cancellation/progress cleanup. The Python FBX importer was used for the real pack after the newer native importer stalled. This is importer compatibility evidence, not a universal security sandbox or a promise that every Blender asset can be read safely.
