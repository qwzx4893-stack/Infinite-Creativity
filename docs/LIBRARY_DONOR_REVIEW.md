# مراجعة مكتبات الأصول ودمج النتائج — v0.8

تاريخ البحث والتحقق: 2026-10-15. الهدف هو مكتبة أصول فنية متعددة الوسائط يتصفحها الوكيل داخل MCP محلي، وتبقى ملفاتها وبياناتها عند المصادر. هذه مراجعة للمشاريع المناسبة التي عثرنا عليها، وليست ادعاء بفحص كل مستودع في GitHub أو إثبات أننا الأكبر عالميًا.

## ما راجعناه ولماذا

شمل الاستكشاف بحث GitHub وقراءة وثائق وعقود بيانات وشيفرات تكامل من المصادر الأصلية. اخترنا المكتبات التي تجمع أصولًا أو حزمًا متنوعة، وقوائم الانتقاء الواسعة التي تساعد في اكتشاف ناشرين جيدين. ميزناها عن محركات بحث الإنترنت وخوادم MCP الخاصة بموقع واحد. نجوم المستودع وعدد روابطه لا يثبتان جودة الأصول أو صلاحية إعادة استخدامها.

## الدمج الوظيفي

- `build_creative_kit`: حتى ست احتياجات معنونة، لكل منها نوع أو قسم دقيق. يجلب نتائج حية، ويوازن المصادر، ويدمج الترتيب وملاءمة كلمات الاتجاه الفني. يعيد المرشحين المقبولين والمراجعة المعلقة والأخطاء والمؤشرات بصورة منفصلة. لا ينتج درجة جمال مزعومة أو يحفظ مجموعة عناصر.
- `assess_asset_fit`: يختبر الصيغة، الهيكل المستهدف، الوحدات، المحور، التحريك، وعدد المثلثات أو الأبعاد عند توافر دليل. النتيجة قد تكون غير متوافقة أو غير متحقق منها أو متوافقة حسب تصريح الناشر. لا يفترض توافق هيكلين أو يستعمل حجم صورة الغلاف بدل الأصل.
- `review_library_board`: صورة MCP مؤقتة من 1 إلى 8 معاينات مفحوصة ومرقمة، مع معلومات الترخيص لكل عنصر. هذه أداة رؤية للوكيل، دون موقع أو واجهة بشرية أو معرض محفوظ. العناصر المرجعية لا تكتسب حق نسخ الأصل.
- تحديد المنتج الأصلي يكمل بصمة الملف لكشف بعض نسخ Kenney في المرايا. تبقى إزالة التكرار محدودة بالطلب وإيصالات التنقل؛ لا يوجد سجل عالمي دائم أو وعد بإزالة كل تشابه بصري.
- مسار الحزم الكبيرة يقرأ مجلدات مختارة ويتابع بمؤشرات. قد تكون نافذة فارغة مع وجود استمرار، فلا تعني نهاية المكتبة.
- دعم `EXT_meshopt_compression` يوسع نموذج الفحص مؤقتًا في الذاكرة؛ التسليم يحتفظ بملف المصدر المضغوط وبصمته. GLB ذات الخامات الخارجية تحتاج قائمة ملفات مرخصة ومراجعة مختارة. لا يسمح المصير بطلب ملفات عشوائية من روابط داخل النموذج.

شيفرة [اختيار المجموعة والتوافق](../src/infinite_creativity/creative_kit.py)، [المقارنة البصرية](../src/infinite_creativity/review_board.py)، [فك ضغط الفحص](../src/infinite_creativity/meshopt_review.py). هذه تطبيقات جديدة للمشروع؛ لم ننسخ شيفرات المستودعات المذكورة بالجملة. تبقى حقوق الأصول عند أصحابها، ويجب الحفاظ على الإسناد وتسجيل التعديلات عندما يشترط الترخيص ذلك.

## تقييمي الصريح

النتيجة أقوى وظيفيًا من تجميعة روابط: يمكن تصفح الحزم والأصول، اختيار الملف، مشاهدة معاينة، وفحص الأصل وتسلمه داخل MCP. صار اختيار مجموعة متناسقة متعدد الوسائط مدعومًا بأدوات أوضح. لكنها ليست مكتبة فُحصت كل أصول الإنترنت داخلها، ولا يوجد أساس لإعلانها أكبر أو أفضل مكتبة عالميًا.

الإعداد الحالي: **389 تعريف اتصال، 324 نطاقًا افتراضيًا بعد قواعد التوجيه وإزالة الأسماء البديلة، 12 عائلة و81 قسمًا نهائيًا و25 سمة اتجاه فني، و36 أداة MCP**. هذه أرقام إعداد، لا عدد مواقع مستقلة ولا عدد أصول مقبولة. ثلاثة موصلات مكتبات جديدة قد تكشف كثيرًا من العناصر، لكن التراخيص والملفات والأصالة والفحص تقلص ما يمكن استعماله فعليًا.

التحديث يعني إعادة القراءة عند كل طلب؛ لا تعني هذه العبارة وجود تنزيل مجدول أو نسخ احتياطي للمواقع. التعطل وحدود GitHub وزمن الاستجابة قد تخفض النتائج. الفحص التقني وكشف المحتوى الجنسي/الإيحائي مؤتمتان ولهما أخطاء؛ الجودة الفنية النهائية تحتاج حكم الوكيل من المعاينات. الأسلوب البسيط المقصود لا يُستبعد لمجرد بساطته. لا يمكن أن يجتمع شرط عدم حفظ أي فهرس مع ضمان بحث فوري شامل في ملايين العناصر أو عدد عالمي دقيق.

انظر [التحقق من v0.8](V08_VERIFICATION.md) للفرق بين ما اختُبر فعليًا وبين إمكانات الإعداد.

## مرجع تقني إضافي

استخدمنا Context7 لمراجعة عقود MCP، وأبقينا حزمة Python SDK في السلسلة `mcp>=1.28,<2` المتوافقة مع التطبيق بدل نقل أمثلة SDK v2 بلا تحقق. استُخدم context-mode لتحليل البحث والمخرجات. تعتمد قراءة الضغط على حزمة Python `meshoptimizer==0.2.30a0`، وهي اعتماد برمجي منفصل يستند إلى [meshoptimizer](https://github.com/zeux/meshoptimizer) ذي ترخيص MIT؛ قد يتطلب تثبيتها مترجم C++ لعدم وجود عجلات جاهزة لكل منصة. لا تُثبت ببدء MCP ولا تجلب أصولًا فنية.
