# Admission, curation and reference policy

Explicit sexual content, nudity, pornography, fetish imagery, obscene gestures and explicit language are excluded. Public accessibility alone does not grant reusable rights. Never bypass authentication, paywalls, subscriptions, Drive confirmation/quotas, provider limits or terms.

Reusable items need per-item or explicit scoped media licenses. A software repository license does not automatically license bundled art. Mixed packs are read through scoped original notices; unknown, NC, sampling+, restricted AI/service use and paid originals remain unavailable. FSD50K's dataset metadata license does not override individual recording licenses. The current Sonniss bundle terms restrict raw-file/service distribution and AI use, so it is not treated as an original-file provider. Blender subscription vault assets are not ingested.

Metadata filtering recognizes explicit terms and separates potentially suggestive language into a contextual-review quarantine. Ordinary words such as breastplate, anime, cartoon and intentionally low-poly/minimal art are not rejection rules. A text match is not a visual safety verdict.

The optional local ONNX image classifier is pinned by revision and SHA256. It records five-class probabilities, crop coverage, image hash, review scope and the conservative threshold. Ambiguous or suggestive results are quarantined, without permanent deletion on a model alone. `preview-screened` describes recorded images only: a thumbnail cannot certify every surface of a 3D model, an animation, a ZIP, or the spoken content of an audio recording. Coverage is explicit in `catalog_stats` and public snapshots. There is no claim of perfect contextual/innuendo detection or complete visual inspection of the entire inventory.

All browse/search/facet paths suppress quarantines, rejected technical media and exact duplicate aliases. Content tools refuse quarantines and references. Changed upstream revisions invalidate old evidence. Operators can retain review evidence in the public `curation` table; private sessions, downloaded originals and models are excluded from exports. Technical validation is distinct from aesthetic judgement, which remains unassessed unless an actual review is recorded.

Visual studies expose only an indexed creator's public presentation thumbnail through native MCP image content, with credit and a study-only notice. Some studied packs have paid variants. This grants no rights to reproduce the thumbnail as a project asset, train a model, or fetch paid originals. Preview-only records have no original file manifests; all original download, code, binary resource and bundle tools reject them. Public thumbnail display does not bypass gated high-resolution previews or premium prompt access.

Original files remain untrusted. Retrieval uses fixed public HTTPS hosts, global DNS checks, byte/decompression budgets, original hashes and ZIP CRC checks. Source/SVG text is returned without execution. Google Drive parser data is decoded without evaluating JavaScript; uncertain listing completeness prevents pack reconciliation. Partial failed sources preserve their previous records.

Report unwanted or incorrectly licensed entries by catalog ID and canonical URL in an issue, without attaching offensive imagery or credentials. Durable exclusions in `src/infinite_creativity/data/exclusions.json` suppress reingestion and content access. Resync, republish and restart after policy changes.

The [first raster audit](REVIEW_AUDIT_V03.md) documents confident false positives on stylized game graphics and their contextual correction. Model flags are triage. `apply-reviews` accepts explicit operator decisions bound to revision and recorded media SHA256; a model flag alone never justifies permanent removal. Changed original bundles invalidate old decisions.
