The original list has **not** been fully integrated. A registered website is not an indexed library inventory. Unsupported or unimplemented providers do not contribute reusable items. No paid originals, authenticated content or provider restrictions are bypassed.

Poly Haven uses its public full asset inventory, with originals/file manifests retrieved on demand. The implementation does not bulk-store its binaries in Git. Uiverse and Motion Primitives expose original code inside MCP. Codrops packs expose code, shaders and notices inside MCP; external image/font/library requirements remain explicit. Mapcn source is MIT while default CARTO map tiles have separate service terms.

Other item-level providers include ambientCG, Kenney, scoped KayKit/Quaternius/Duelyst and CC0 game pack repositories, FSD50K, official Blender demo subsets and licensed grading LUT collections. See release `manifest.json` for exact usable counts by medium, raw records, curation coverage and source health. Large icon inventories are counted separately; general recommendations sample media independently.

Original media stays at the provider. Internal item IDs, file manifests, previews, code reading, native audio, model inspection, bundles and chunk tools present the supported items as one MCP library. An upstream quota or inaccessible original can still prevent first retrieval, and is reported in item availability rather than represented as a working download.

Primary provider checks: [21st terms](https://21st.dev/terms), [Aceternity licence](https://ui.aceternity.com/licence), [Mapcn source and basemap terms](https://github.com/AnmolSaini16/mapcn), [Codrops demos](https://tympanus.net/codrops/demos/), [Uiverse source](https://github.com/uiverse-io/galaxy).
