# التوسع إلى مجموعات بملايين السجلات — v0.10.0

أصبح MCP يستطيع القفز مباشرة إلى مواضع متقدمة في مجموعة صور منتقاة لدى ناشرها، مع توسعة فعلية للمجسمات والعينات الموسيقية وانتقالات الفيديو وكود الموشن. بقي التشغيل محليًا عبر stdio؛ لا توجد واجهة بشرية أو نسخة من قاعدة العناصر أو الصور أو المجسمات أو الصوت أو المتجهات داخل المستودع. تُجلب بيانات المصدر من جديد لكل طلب، وتُحذف ملفات الفحص المؤقتة عند انتهاء الطلب.

## المصادر المضافة ومعنى أعدادها

| المصدر داخل MCP | الزيادة الفعلية وطريقة الوصول | أساس الانتقاء والحقوق |
|---|---|---|
| `pd3m` | API عام بلا حساب أعاد **3,301,062 سجلًا**؛ يمكن طلب مواضع بعيدة مباشرة دون اجتياز الصفحات السابقة. توجد صور وأعمال فنية ومواد تاريخية وخلفيات متنوعة. | [الناشر يصف PD3M بأنه مجموعته ذات الدرجات الجمالية الأعلى](https://huggingface.co/datasets/Spawning/PD3M). يشترط الموصل رابط CC0 أو Public Domain Mark لكل صورة، وبصمة MD5، وضلعًا أقصر لا يقل عن 512 بكسل وأطول لا يقل عن 1024. تُفحص الصورة الأصلية المتاحة قبل عرضها. |

| `meta-open-sound` | **1,075 عينة OGG عامة فعلية** ضمن ثلاث حزم: بيانو، غيتار نايلون وغيتار فولاذي. كل عينة عضو في بيان الحزمة الحالي ولها ملف موجود فعلًا وبصمة Git. | [عينات Meta Creative Audio](https://github.com/facebookincubator/Meta-open-sound) منشورة بـCC0. يختلف بيان مواصفات ملفات WAV الرئيسية عن ملفات OGG العامة التي يستطيع MCP تسليمها؛ لا تُختلق ملفات WAV غير الموجودة. |
| `gl-transitions` | ملفات GLSL الأصلية للانتقالات، من الإصدار الحالي لحزمة npm العامة؛ تُسلّم داخليًا مع إشعارات الترخيص. | [المجموعة الرسمية](https://github.com/gl-transitions/gl-transitions) تعلن MIT، ويشترط الموصل أيضًا إعلان MIT صريحًا داخل كل ملف. يحتفظ بالمؤلف والوصف والوسوم من ترويسة المصدر، ويتحقق من بصمة الحزمة. |
| `manim-motion-examples` | ملفات Python الأصلية من مجلد الأمثلة الرسمي الحالي، لصناعة رسوم موشن ومشاهد متحركة. | [Manim الرسمي](https://github.com/ManimCommunity/manim/tree/main/example_scenes) مع [رخصة MIT الحالية](https://github.com/ManimCommunity/manim/blob/main/LICENSE). تصل ملفات الكود والترخيص؛ لا يُشغَّل كود المصدر أو يُدّعى توفير فيديو مُنفَّذ لم يُفحص. |

**3,301,062 هو عدد سجلات المجموعة لدى الناشر، وليس عدد عناصر اجتازت كلها فحصنا أو عددًا عالميًا فريدًا بعد إزالة التكرار.** لا نجمعه مع أرقام Openverse أو Wikimedia أو Objaverse كأنها مخزون مستقل غير متداخل. كذلك لا نعد نسخ OGG/WAV أو معاينات الملف أصولًا إضافية لزيادة الرقم.

Public Domain Mark تعيين لحالة الملكية العامة، وليس رخصة CC0؛ لذلك يظهر باسم مستقل `LicenseRef-Public-Domain-Mark-1.0`. رخصة بيانات PD3M الوصفية CDLA-Permissive-2.0 منفصلة عن حق الصورة المحدد في السجل. الملف المتاح نسخة يستضيفها الناشر، ولا نعد بأنها أعلى دقة تاريخية عند المؤسسة الأصلية.

## كيف يتصفحها الوكيل

الأداة الجديدة **`browse_asset_catalog`** تفتح نافذة داخل المكتبة الموحدة وتُرجع بطاقات العناصر المقبولة، والعناصر المعلقة للفحص، والأقسام والتراخيص وأساس الانتقاء والمؤشر التالي. لا يحتاج الوكيل إلى فتح موقع خارجي للحصول على معاينة أو قائمة ملفات أو بايتات الأصل المختار.

```json
{"tool":"browse_asset_catalog","arguments":{"source":"pd3m","offset":2000000,"limit":3}}
{"tool":"browse_asset_catalog","arguments":{"source":"objaverse-curated","partition":12,"offset":0,"query":"cartoon","limit":3}}
```

بعدها تُستخدم `library_page` مع المؤشر الناتج، أو `open_asset_package` مع معرّف عنصر مختار للحصول على الفحص والمعاينة والملف داخل MCP. لحزم الآلات تُستخدم `open_library` أو `library_packs` ثم `get_library_pack`؛ العضوية دقيقة لكل آلة، وليست مجلد روابط فارغًا.

يعرض `sources[].catalog` امتداد بيانات المصدر والموضع الجاري والاستبعادات، مع `admitted_unique_assets: null`. وتشير `catalog_navigation` في `list_sources` إلى المصادر التي تدعم القفز. توجد الآن **399 خانة توجيه، منها 334 في الاختيار الافتراضي، و39 أداة MCP و83 قسمًا نهائيًا و25 توجهًا فنيًا**. خانات التوجيه ليست عدد مواقع مستقلة أو عدد أصول. أُضيف قسم للعينات الموسيقية وقسم للتصوير؛ دور الصورة يعتمد على البيانات الوصفية ولا يساوي تصنيفًا فنيًا مؤكدًا من البكسلات.

## الجودة والفحص أثناء الجمع

يستبعد الموصل بيانات المحتوى الجنسي والإيحائي، والتراخيص غير المقبولة، والسجلات غير المكتملة، والمسارات غير المعتمدة، ثم يعمل فحص الوسائط المعتاد قبل عرض الأصل. تُستخدم بصمات الملفات والبكسلات والهويات الأصلية لإزالة التكرار ضمن نطاق الطلب ومؤشرات التنقل المحدودة. تبقى البساطة المتعمدة والـlow-poly صالحتين؛ لا يوجد شرط يلزم كل مجسم بخامة واقعية أو عدد مضلعات مرتفع.

للمجسمات يشترط الانتقاء إما اختيار فريق المصدر أو 25 إعجابًا على الأقل، في البيانات المؤرشفة والحالية، مع هندسة معلنة قابلة للفحص. هذه مؤشرات انتقاء، وليست شهادة بأن كل عمل ممتاز فنيًا. تظهر `quality_evidence` في البطاقات، ويستطيع الوكيل مقارنة المعاينات عبر `review_library_board` و`rank_library_items` لاختيار التوجه والتناسق المناسبين.

الفحص الفعلي كشف نموذجًا مؤرشفًا حُذف من مصدره، وآخر تغيرت حقوقه إلى ترخيص مدفوع؛ استُبعدا. كما حجب المصنف نموذجًا آخر بسبب تقدير خطر المحتوى؛ لم نخفف الفلاتر لتجاوز القرار. ولذلك لا تمثل أحجام الأرشيف أعداد الملفات التي نضمن إتاحتها حاليًا.

## التحقق الفعلي

شُغّلت الحالات التالية عبر **عميل MCP حقيقي وخادم stdio**، دون مفتاح مزود ودون حفظ الأصول الناتجة. هذه أزمنة تشغيل مرصودة وليست ضمانًا للأداء:

| المهمة | الناتج الأصلي المفحوص، مع إشعاراته حيث وجدت | النتيجة داخل MCP | الزمن المرصود |
|---|---:|---|---:|
| صورة من الموضع 2,000,000 في PD3M | 2,496,365 بايت | معاينة أصلية وفحص ودفعة بايتات | 13.687 ثانية |
| مجسم من Objaverse مع تحقق حالي للحقوق | 3,360,760 بايت | GLB ومعاينة محلية وفحص ودفعة بايتات | 23.531 ثانية |
| عينة آلة موسيقية | 141,196 بايت تشمل الترخيص | ملف OGG ومقتطف استماع؛ نجحت إعادة جلب مقتطف لاحق مع تحقق البصمة | 7.813 ثانية |
| انتقال فيديو | 2,506 بايت تشمل الترخيص | كامل GLSL المختار: 1,209 بايت، مع إشعار الترخيص | 1.000 ثانية |
| مثال موشن | 6,429 بايت تشمل الترخيص | كامل Python المختار: 5,357 بايت، مع إشعار الترخيص | 2.704 ثانية |

اختبار لاحق لمسار `get_library_pack` أكد أن حزمة البيانو تعيد أعضاء `meta-piano` فقط، ثم نجح تسليم الصوت ومعاينته وإعادة التحقق من مقتطفه؛ استغرق مسار الاختيار من الحزمة والتسليم 10.610 ثانية في ذلك التشغيل.

نجح **174 اختبار Python**. تشمل الإضافات القفز المباشر إلى مواضع بالملايين، وعدم خلط PDM وCC0، وتغير الصفوف والتراخيص والمُنشئ وإتاحة المصدر، ومنع الروابط الخاصة، وحد الذاكرة المستقلة لفك ضغط البيانات، وبصمة الصورة، واستمرار التنقل بعد الاستبعادات، والعضوية الدقيقة للحزم ومنع اختلاق WAV، وترخيص كل Shader وبصمة حزمة المصدر. يشمل التحقق أيضًا اختبارات محول WebMCP وفروق Git.

```bash
python -m unittest discover -s tests -q
node tests/webmcp.test.mjs
python scripts/verify_live_workflows.py --case millionth-art --case curated-model --case instrument --case transition --case motion-code
```

## الحدود التي تؤثر في الاستعمال

واجهتا البحث الشامل والتصفية لدى مزود PD3M تعثرتا أثناء الدمج؛ لم أصفهما بأنهما تعملان. يستخدم الموصل واجهة الصفوف التي ثبت عملها، وتغطي مرشحات النص/التوجه/القسم **نافذة من 100 سجل** في PD3M أو **قسم البيانات الحالي** في Objaverse. يمكن القفز إلى موضع آخر مباشرة ومتابعة المؤشرات، وتبقى مصادر البحث العام الأخرى موجودة. البحث الشامل الفوري في ملايين هذه الصفوف دون فهرس محفوظ أو خدمة بحث عاملة لدى المصدر ليس ميزة مثبتة هنا. توثق [واجهة Hugging Face الرسمية](https://huggingface.co/docs/dataset-viewer/en/quick_start) واجهات الصفوف والبحث والتصفية، ويبين [توثيق التصفية](https://huggingface.co/docs/dataset-viewer/en/filter) أن التغطية قد تكون جزئية للمجموعات الكبيرة.

دُرس Objaverse-XL، لكن الملايين المعلنة فيه لا تساوي ملايين أصول حرة جيدة جاهزة. تحتوي صفوف على حقوق غير محددة، وتعثر البحث وبعض النوافذ البعيدة؛ لم نضف هذه الأعداد إلى نطاق الإتاحة. أضفنا مسار الأصول الفردية الذي أمكن إثبات حقوقه وتسليمه.

مع عدم حفظ فهرس أو قرارات دائمة، لا يوجد عدد عالمي مُثبت للأصول المقبولة أو إزالة تكرار عالمية دائمة. وتبقى تقديرات السلامة والجودة الآلية قابلة للخطأ؛ وجود درجة جمالية أو عدد إعجابات لا يجعل كل أصل مناسبًا لكل استخدام. التوسع الحقيقي هنا هو الوصول المباشر واسع النطاق والانتقاء أثناء الطلب وتسليم اختيارات متنوعة فعليًا، مع إظهار القيود للوكيل.
