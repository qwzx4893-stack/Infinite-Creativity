# إصلاح نقاط الضعف وتوسيع الوصول — v0.9.0

تاريخ التحقق: 2026-10-16 بتوقيت بغداد. هذه نتائج تنفيذ واختبارات فعلية، مع فصل ما يمكن ضمانه هندسيًا عن حدود المصادر والفحص الآلي. لم ننشئ واجهة بشرية أو خدمة مستضافة، ولم نحفظ كتالوج عناصر أو أصولًا أو فهرس متجهات.

## ما تغير

| نقطة الضعف | الإصلاح المنفذ | حدود النتيجة |
|---|---|---|
| عمق التكامل يختلف بين المصادر | خمسة موصلات إضافية بملفات أصلية؛ إصلاح اكتشاف `LICENCE.md` الذي كان يمنع عناصر Motion Primitives؛ توحيد أسماء ملفات الترخيص البريطانية والأمريكية؛ منع الاسم البديل القديم من تجاوز موصل الحزم المتخصص | الموصل لا يثبت إتاحة كل عنصر في الموقع. التراخيص والواجهات والصيغ المدعومة تحدد التغطية |
| تكرار القراءة والفحص يبطئ الاستعمال | اتصالات HTTPX يعاد استخدامها داخل الطلب، دمج القراءات المتزامنة للرابط نفسه، بحث ومعاينات متوازية بحد أقصى 3 مهام، فحص توافق من البيانات الحالية دون فحص وسائط غير لازم | لا توجد ذاكرة لبيانات العناصر بين الطلبات، لذلك يبقى جلب البيانات والأصل ضروريًا |
| يحتاج الحصول على أصل إلى عدة استدعاءات | `open_asset_package` يجمع الحقوق والفحص الكامل للملف المختار ومعتمَداته وقائمة الملفات والنصوص المحدودة للتراخيص والمعاينة وأول بايتات الأصل في استدعاء واحد | الأصل الكبير يحتاج استكمالًا عبر `next_offset`. لا تُرسل الحزمة كلها بلا حدود داخل رسالة MCP |
| معاينة أصل سبق فحصه تعيد عملًا مكلفًا | معاينة GLB الموقعة تعيد جلب الملفات والتحقق من بصماتها الحالية، ثم تصيّر وتفحص المعاينة الجديدة؛ لا تكرر فحص النموذج الكامل عندما تتطابق كل الملفات | لا تُستعمل صورة غلاف لتفويض نموذج غير مفحوص. تغير البيانات أو البصمة يوقف المسار. للصيغ الأصلية الأخرى مسار أبطأ عند الحاجة |
| التكرار لا يقتصر على تطابق الملف المضغوط | بصمات البكسلات المفكوكة، وتطبيع بنية GLB، وإبقاء بصمات الملفات والحزم والمنتج الأصلي. أصلان مختلفان بغلاف واحد يبقيان منفصلين | لا ندعي اكتشاف كل تشابه هندسي أو بصري. إيصالات التنقل محدودة ولا يوجد سجل تكرار عالمي محفوظ |
| جودة النتائج تحتاج دليلًا أوضح | صلاحية فك الملف، أبعاد البكسلات، شفافية فعلية، معلومات الصوت الأصلي، توافق معلن مقابل مجهول، ولوحة معاينات للوكيل. إصلاح عدم الخلط بين رسم بكسل متناثر وصورة شفافة فارغة | هذه أدلة تقنية؛ لا توجد درجة جمال مختلقة. البساطة الفنية المقصودة لا تُرفض لمجرد قلة التفاصيل |
| فلاتر النص يمكن التحايل عليها | معالجة الحروف العريضة، والعلامات المركبة، والتشكيل، والمحارف الخفية، وبعض المحارف المتشابهة والكتابة بالأرقام، في البيانات والنصوص الأصلية | لا يعني ذلك فهم كل لغة أو سياق أو تلميح جنسي بصورة مثالية |
| الأعطال والنتائج الناقصة غير واضحة دائمًا | `probe_library_sources` يفصل حالات الدليل، ويعرض توقيتات وأسبابًا؛ أخطاء العناصر ظاهرة؛ إعادة محاولة محدودة ثم استئناف صريح يحافظ على الموضع | تعطل موقع أو تغيير عقد الوصول لا يمكن إلغاؤه من طرفنا. لا نتحايل على حساب أو حماية أو رفض وصول |

## المصادر الجديدة التي نجح منها التسليم

| المصدر | الأصول وطريقة الوصول | عقد الحقوق |
|---|---|---|
| [Poly Pizza](https://poly.pizza/explore) | صفحات JSON عامة للمجسمات مع متابعة صفحات البحث، ثم GLB العام. إعلانات الحزم المدفوعة منفصلة ولا تدخل النتائج | CC0 أو CC BY صريح لكل نموذج، مع المؤلف والإسناد. لا يُستخدم مسار مفتاح أو توكن لتنزيل ملفات إضافية |
| [TextureCan](https://www.texturecan.com/) | بحث فعلي، صفحات مواد، أرشيفات دقة مختلفة، ثم خرائط داخل الحزمة عبر `get_library_pack` وواجهات الأرشيف الداخلية | [إهداء CC0 الحالي](https://www.texturecan.com/terms/) مع روابط الأرشيف العامة |
| [Met Open Access](https://metmuseum.github.io/) | واجهة بحث `v1.1` المقسمة إلى صفحات، ثم صور الأصل والبدائل | يشترط `isPublicDomain=true` لكل كائن؛ البيانات العامة وحدها لا تكفي. واجهة البحث القديمة أعادت HTTP 410، ولذلك لم نستخدمها |
| [Cleveland Open Access](https://openaccess-api.clevelandart.org/) | صور الويب والطباعة والنسخة الكبيرة حيث يعرضها سجل الكائن | يشترط `share_license_status=CC0`؛ [صور الكائنات المحمية لا تدخل الأصول](https://www.clevelandart.org/open-access) |
| [Incompetech](https://incompetech.com/music/royalty-free/) | كتالوج الموسيقى الحالي، صفحة المشغل لكل مقطوعة، MP3 عام، وعضوية مجموعات الناشر | CC BY 4.0 مع إسناد Kevin MacLeod، بعد التحقق من عقد المشغل الحالي. [الترخيص المدفوع بلا إسناد](https://incompetech.com/music/royalty-free/licenses/) ليس مسارنا |

عرضت صفحة Poly Pizza العامة أكثر من عشرة آلاف نموذج وقت البحث، واحتوى `pieces.json` لدى Incompetech على 1,443 سجلًا. يصف Cleveland عشرات آلاف الصور المفتوحة. هذه مؤشرات إلى حجم مصادر الناشرين؛ **لم نجمعها كعدد أصول جديدة أو فريدة أو مفحوصة بالكامل**، وقد تتقاطع مع مصادر وفهارس أخرى كانت متصلة أصلًا.

الإعداد الآن **394 تعريف اتصال و329 نطاق توجيه افتراضي، و38 أداة MCP، و12 عائلة و81 قسمًا نهائيًا و25 سمة اتجاه فني**. هذه ليست 394 موقعًا مستقلًا، ولا عددًا عالميًا للأصول المقبولة.

المصادر غير المعتمدة بعد الفحص: [FreePD مغلق](https://www.freepd.com/)، وتنزيلات ccMixter العامة أعادت HTTP 403 لعدة عينات رغم عمل بياناتها العامة؛ لذلك لا يوجد له موصل مسجل في المكتبة. فُحص CGBookcase وShareTextures للبحث، ولم نُضف وصولًا أصليًا لم نكمل إثباته. لم نُعد المواقع التي تتطلب حسابًا أو مفتاحًا إلزاميًا.

## تحقق حي عبر MCP محلي

شغّلنا العميل الحقيقي عبر stdio. نجحت الحالات الست في تشغيل قبول واحد، مع فحص الأصل قبل إخراج بايتاته. الأرقام أدناه تشمل الاكتشاف والاختيار؛ عدد البايتات هو مجموع ملفات الاختيار المفحوصة، وليس حجم كتالوج محفوظ.

| المهمة | الملف/النطاق الذي فُحص | بايتات الأصل/المعتمَدات | زمن التشغيل المرصود | نتيجة MCP |
|---|---|---:|---:|---|
| نموذج شجرة من Poly Pizza | GLB | 118,032 | 6.7 ثوانٍ | نص، صورة مفحوصة، قائمة ملفات، وأول 65,536 بايتًا |
| خامة من حزمة TextureCan | خريطة JPG من داخل ZIP، مع تنقل داخلي للحزمة | 82,235 | 10.8 ثوانٍ | نص وصورة وبايتات الأصل، دون زيارة صفحة خارجية |
| عمل فني من Met | JPG أصلي | 2,369,231 | 12.3 ثانية | نص وصورة وبايتات الأصل |
| عمل فني من Cleveland | JPG مرخص CC0 | 567,422 | 5.8 ثوانٍ | نص وصورة وبايتات الأصل |
| موسيقى Incompetech | MP3 مفحوص بالكامل | 615,563 | 12.7 ثانية | نص، مقتطف WAV للاستماع، وبايتات MP3 الأصلية منفصلة |
| مكوّن Motion Primitives | TSX وLICENCE.md | 5,883 | 3.3 ثوانٍ | تسليم كود TSX كامل (4,806 بايتات)، وإشعار الترخيص ضمن النطاق |

المقتطف الصوتي ليس الأصل الإنتاجي: هو معاينة أحادية القناة بتردد 22,050 هرتز، حتى 30 ثانية. يحتفظ مسار البايتات بملف الإنتاج الأصلي. جُرّب أيضًا استدعاء استماع جديد عند الثانية 1 لمدة ثانية، بعد إعادة جلب الأصل والتحقق من بصمته الموقعة، ونجح إخراج صوت MCP.

أثبت اختبار أداة فحص المصادر أن عينة Met وعينة Cleveland كانتا `original-sample-admitted`، وليس مجرد بيانات أو أغلفة. هذا دليل عينة حالية، لا شهادة لكل مخزون المصدر.

## الاختبارات وإعادة التحقق

النتيجة النهائية محليًا: **155 اختبار Python ناجحًا**، ونجاح اختبارات محول WebMCP، ونجاح فحص فروق Git. نجحت كذلك المهام الست الحية أعلاه، وإعادة جلب مقتطف الصوت والتحقق منه، وفحصا المصدرين الفنيين عبر `probe_library_sources`. أُعيد اختبار تسليم مكوّن الواجهة مع ملف ترخيصه بعد التعديلات النهائية.

تشمل الاختبارات عقود الحقوق لكل مصدر، ومنع المنتجات المدفوعة من نتائج النماذج، وتغير الترخيص، والعضوية الدقيقة للحزم، وحدود استجابات HTTP المضغوطة، وإعادة التحقق من وجهات التحويل، وعدم إرسال GitHub Authorization إلى مضيف آخر، ودمج القراءات المتزامنة، وتنظيف الطلبات، وفحص النصوص المموهة، والبكسلات، واختلاف ملفات ICC، وبصمات GLB مع الحفاظ على اختلاف التحويلات، وإعادة محاولة المصدر دون فقد الموضع، وإخراج الكود دون تنفيذه.

```bash
python -m unittest discover -s tests -q
node tests/webmcp.test.mjs
python scripts/verify_live_workflows.py --probe
```

يمكن تحديد حالة عبر `--case model` أو `material` أو `met` أو `cleveland` أو `audio` أو `interface`. السكربت يطبع مقاييس وحالات فقط، ولا يحفظ الأصول أو سجلات العناصر أو صوت المعاينة. يحتاج الفحص الإعلامي إلى البرمجيات المحلية المعدّة في README. لا يوجد مفتاح مزود إلزامي؛ قد يساعد `GITHUB_TOKEN` الاختياري في حصة GitHub العامة.

## ما بقي قيدًا حقيقيًا

لا يمكنني أن أعد بصراحة بإزالة كل محتوى جنسي أو إيحائي أو كل تكرار أو كل أصل ضعيف فنيًا بصورة مثالية؛ المصنفات الآلية وحكم الجودة والسياق لها أخطاء. لا يوجد ضمان لإتاحة كل صيغة أصلية أو مشهد ضخم أو كل أصل على كل موقع. للفحص حدود وقت وبايتات وطبقات وإطارات وهندسة، وتبقى الحالات غير المدعومة أو غير المؤكدة معلقة أو محجوبة.

شرطك بعدم حفظ فهرس يعني أن البحث الشامل الفوري وعددًا عالميًا دقيقًا وفحص ملايين العناصر مقدمًا ليست نتائج نملك إثباتها. يستطيع الوكيل الوصول إلى نوافذ وحزم ومصادر واسعة، ثم التحقق من اختياراته داخل MCP. تتحسن الكمية الفعلية المتاحة من المصادر الجديدة والإصلاحات، بينما تبقى أعداد الناشرين وحجم التوجيه منفصلة عن عدد الأصول المقبولة والفريدة.

الحكم الحالي: أصبح المشروع أكثر قابلية للاستعمال ومثبتًا بمهام متنوعة، مع سرعة أفضل وإكمال اختيار الأصل داخل استدعاء واحد. إثبات أنه الأكبر عالميًا أو أنه خالٍ من كل خطأ ليس من نتائج هذا الإصدار.
